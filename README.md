# «Изгиб Питона» — игра «Змейка»

Проект на Python и Pygame, выполненный на основе стартового шаблона Яндекс Практикума.

## Запуск

Нужен Python. В корневой папке проекта выполните:

```bash
python -m pip install -r requirements.txt
python the_snake.py
```

На Windows вместо `python` иногда используется команда `py`.

Управление: стрелки — поворот змейки, `Esc` — выход. Змейка проходит через края поля, ест красные яблоки и растёт. После самоукуса начинается новая игра.

## Проверка

```bash
python -m pytest
```

## Структура

- `the_snake.py` — вся логика игры.
- `tests/` — автотесты из шаблона.
- `requirements.txt` — необходимые зависимости.

Автотесты в папке `tests` оставлены без изменений.
